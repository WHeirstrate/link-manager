## [1.0.0]

### Added
- Menu bar app with a list of quick links and an **Edit Links…** window.
- Targets can be web URLs, apps, files, folders or any URL scheme.
- Automatic favicon scraping for web links.
- Launch at login, enabled on first run.
- Standard text-editing shortcuts (⌘C/⌘V/⌘X/⌘A/⌘Z) in the editor.
